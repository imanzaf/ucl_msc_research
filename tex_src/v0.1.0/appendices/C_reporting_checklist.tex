\chapter{Reporting and Reproducibility Checklist}
\label{app:checklist}

The final thesis and benchmark release should report each item below.

\section{Research claims}

\begin{itemize}
    \item State whether each claim concerns output behaviour, systematic condition effects, user-simulator outcomes, or strategic intent.
    \item Define risk concealment and all subtypes before presenting results.
    \item Report disaggregated failure modes before any composite score.
    \item Name the evaluated model versions and dates; avoid universal claims about all LLMs.
    \item Distinguish confirmatory hypotheses from exploratory findings.
\end{itemize}

\section{Benchmark composition}

\begin{itemize}
    \item Number of generated, revised, rejected, and retained families and instances.
    \item Distribution by segment, stakeholder, interaction mode, source type, risk category, and fact polarity.
    \item Exact fact-pool composition and handling of variable denominators.
    \item Materiality rubric, expected-disclosure rules, reviewer qualifications, and agreement.
    \item Examples of accepted and rejected scenarios.
    \item Test-set contamination and maintenance policy.
\end{itemize}

\section{Model runs}

\begin{itemize}
    \item Provider, exact model/checkpoint, endpoint, access date, and disclosed version.
    \item Temperature, top-$p$, maximum tokens, seed policy, stop conditions, and retries.
    \item Full prompt templates, rendered hashes, and condition-specific differences.
    \item Number of replicates and missing/invalid runs by condition.
    \item Cost or compute, hardware for local models, quantisation, and software environment.
\end{itemize}

\section{Simulation}

\begin{itemize}
    \item User-simulator and outcome-model identities and prompts.
    \item Turn cap, stopping rule, action randomisation, and hidden-information controls.
    \item Persona fidelity and semantic-equivalence checks.
    \item Simulator-family robustness and any evidence of self-preference bias.
    \item Clear statement that simulator outcomes are not human population estimates.
\end{itemize}

\section{Scoring}

\begin{itemize}
    \item Extractor, matcher, judge models, versions, and prompts.
    \item Structured-output validation, retry rates, and invalid outputs.
    \item Fact-match thresholds and treatment of unmatched inferences.
    \item Lexicons, parsers, tokenisation, and span-allocation rules.
    \item Human-validation sampling, annotator training, agreement, adjudication, and automated precision/recall.
    \item Judge-blinding and alternative-judge sensitivity.
\end{itemize}

\section{Statistics}

\begin{itemize}
    \item Preregistered primary endpoint and contrasts.
    \item Power assumptions, clustering, and minimum detectable effects.
    \item Full mixed-model specification, random effects, convergence diagnostics, and software.
    \item Effect sizes, marginal probabilities, confidence intervals, and multiplicity handling.
    \item Treatment of response length as mediator and secondary covariate.
    \item Family-level bootstrap or resampling method.
    \item All exclusions and deviations from the analysis plan.
\end{itemize}

\section{Results presentation}

\begin{itemize}
    \item Absolute rates and eligible denominators for every failure mode.
    \item Per-model and pooled estimates with uncertainty.
    \item Prompt main effects, persona main effects, and prompt-by-persona interactions.
    \item Favourable and neutral fact-retention controls.
    \item Single-turn versus multi-turn, first-turn versus ever-disclosed, and repair metrics.
    \item Belief/action outcomes before and after full-information disclosure.
    \item Robustness checks, including results that weaken the main conclusion.
    \item Qualitative true positives, true negatives, false positives, false negatives, and contested cases.
\end{itemize}

\section{Ethics and release}

\begin{itemize}
    \item Ethics/IRB determination and informed-consent procedure where applicable.
    \item Data-protection and confidentiality assessment.
    \item Copyright and licence status of source artefacts.
    \item Potential misuse and mitigations.
    \item Funding, provider relationships, and financial conflicts.
    \item Repository, archival DOI, licences, benchmark card, and contact/maintenance process.
\end{itemize}
